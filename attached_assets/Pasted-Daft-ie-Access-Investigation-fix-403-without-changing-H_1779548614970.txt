- push notifications

Goal:
Find the simplest reliable way to retrieve real Daft.ie Dublin rental listings and feed them into the existing Daft fetcher.

==================================================
1. Investigate Daft response structure
==================================================

Inspect how Daft.ie serves listing data.

Check:

==================================================

Improve the existing fetcher only if useful:

- Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8

- timeout handling

If still 403, keep clean handling.

==================================================
3. Add optional proxy support
==================================================

Add env-based optional proxy support, but do not require it.

Supported env proposal:
DAFT_PROXY_URL=

Expected behavior:
- If DAFT_PROXY_URL is empty, use direct fetch.
- If DAFT_PROXY_URL is set, route Daft request through that proxy.
- Keep logs clear:
  - direct fetch used
  - proxy fetch used
  - status code
  - normalized listing count

Make this generic enough to work with services like ScraperAPI/Bright Data, but do not hardcode vendor-specific logic unless very small and isolated.
