PAGES TO BUILD
--------------------------------

1. /dashboard
This should be the main logged-in shell.

Use bottom navigation with 4 tabs:
- Home
- Matches
- Filters
- Profiel

--------------------------------
HOME TAB
--------------------------------

Build a clean home overview with:
- greeting: "Hallo, {name}"
- summary card:
  "Met jouw filters verwachten we ongeveer X matches per week"
- progress cards:
  - account status
  - search profile status
- CTA buttons:
  - "Bekijk matches"
  - "Beheer filters"

Use card-based UI, rounded corners, white cards, navy headings, light grey backgrounds where needed.

--------------------------------
MATCHES TAB
--------------------------------

Build a Matches screen using real data from GET /api/matches.

Each match card must show:
- freshness badge (net binnen / nieuw / vandaag / ouder)
- title
- city
- price
- bedrooms
- size_m2
- source
- matched_at or first_seen_at
- CTA button:
  "Bekijk advertentie"

Clicking the CTA opens the original listing URL in a new tab/window.

Empty state:
If there are no matches, show a friendly empty state with CTA:
"Pas je filters aan"

--------------------------------
FILTERS TAB
--------------------------------

Build a search profiles screen using real search_profiles data.

Each search profile card must show:
- city
- min/max price
- min rooms
- min size
- enabled/disabled state

Actions:
- edit
- delete
- add new search profile

Show a max of 4 search profiles.
If fewer than 4 exist, show an add card/button.
