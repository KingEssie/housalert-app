Build the PropertyPal Ireland source for HousAlert.

Context:
HousAlert already has:
- stable Ireland ingestion pipeline
- Daft.ie working live via ScraperAPI
- source health
- notification traces
- Ireland scheduler
- matching + push pipeline
- PropertyPal discovery results showing:
  - __NEXT_DATA__ available
  - listing URLs visible
  - prices visible
  - listings accessible without render=true
  - score 5/5 for scrapeability

Goal:
Implement PropertyPal as the second reliable Dublin source using the SAME lightweight pattern as Daft.ie.

IMPORTANT:
Do NOT touch:
- service worker
- push notifications
- VAPID/FCM
- Stripe/paywall
- Germany infrastructure
- matching architecture
- notification traces
- admin systems

Do NOT add:
- browser automation
- Playwright
- Puppeteer
- render=true
- heavy dependencies
- new scraper frameworks

Keep implementation lightweight and pragmatic.

==================================================

==================================================

==================================================

Fetch Dublin rental listings from PropertyPal.

Requirements:
- use existing proxy helper if needed
- direct fetch preferred
- proxy fallback acceptable
- NO render=true

Parse listing data from:
- __NEXT_DATA__
- initialState
- embedded JSON
- whichever stable SSR structure exists

Requirements:
- source = "propertypal"
- stable externalId
- title
- price (numeric if possible)
- location
- absolute URL
- imageUrl if available
- bedrooms if available
- latitude/longitude if available
- createdAt/listedAt if available

Skip invalid listings safely.
