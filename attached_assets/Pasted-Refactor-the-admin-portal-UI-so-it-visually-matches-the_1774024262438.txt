Refactor the admin portal UI so it visually matches the main user app, not just in color but in full component styling.

IMPORTANT:
- Do NOT change admin functionality
- Do NOT change routes or data logic
- Only align the visual design system with the user-facing app

==================================================
1. MATCH CARD / PANEL STYLING TO USER APP
==================================================

Current issue:
- admin cards/panels still feel like a separate dashboard product
- shadows, radius, borders, and spacing do not match the user app

Fix:
- use the SAME card styling system as the main user app:
  - same corner radius
  - same shadow strength
  - same border treatment (or no border if the user app uses mostly shadow)
  - same white card surfaces
  - same spacing rhythm

Apply to:
- metric cards
- funnel cards
- top summary cards
- alert cards
- all admin content panels

==================================================
2. MATCH BOTTOM TAB BAR TO USER APP
==================================================

Current issue:
- admin tab bar icons and labels are too small
- spacing does not match the user app
- it feels like a different tab bar system

Fix:
- use the SAME bottom tab bar proportions as the user app:
  - same bar height
  - same icon size
  - same label font size
  - same spacing between icon and label
  - same active/inactive visual behavior

  - same dark text/icon treatment

Apply this without changing the admin navigation structure.

Goal:
The admin tab bar should feel like the admin version of the same app, not a separate dashboard UI.

Fix:

==================================================

Current issue:
