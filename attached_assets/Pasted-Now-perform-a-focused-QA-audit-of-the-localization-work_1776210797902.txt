2. CHECK FOR THESE PROBLEMS
==================================================

For each screen above, inspect and report:

A. Hardcoded Dutch still visible
- any Dutch strings still showing when German or English is selected

B. Mixed language screens
- e.g. title in German but button in Dutch

C. Missing translation keys
- raw translation keys visible
- blank text
- fallback issues

D. Unnatural localization
- German or English text that sounds literal, robotic, or Google-Translate-like
- awkward product wording
- overly formal or unnatural phrasing

E. UI breakage caused by translation length
- wrapped buttons
- overflowing labels
- broken spacing
- clipped titles

F. Placeholder / template bugs
- placeholders like [ADRES], [[ADRES]], etc. rendered incorrectly
- translated placeholders that should remain dynamic
