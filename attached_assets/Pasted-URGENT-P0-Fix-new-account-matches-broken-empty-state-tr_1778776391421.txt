3. FIX PAID SUBSCRIPTION STILL SHOWING TRIAL
==================================================

Subscription page still shows:
- “Proefperiode”
- “Proefperiode eindigt 28 mei 2026”

But the user purchased a paid 2-month plan.

Investigate:
- frontend subscription data source
- backend /api/subscription response
- local DB subscription fields
- Stripe subscription fields
- whether stale trial data remains in DB
- whether frontend chooses trial_ends_at before status/plan
- whether status is still trialing incorrectly
- whether plan name is overwritten by trial logic

Correct rules:
- If Stripe status = active and a paid price exists:
  show paid plan, never trial
- Paid 2-month plan:
  title: “Premium 2 maanden”
  status badge: “Actief”
  if cancel_at_period_end=true:
    status badge: “Opgezegd”
    subtitle: “Loopt af op [current_period_end]”
  expiry date: Stripe current_period_end
- Trial only:
  title: “Proefperiode”
  status badge: “Proefperiode”
  expiry: trial_end

Frontend rule:
Do NOT infer trial from trial_ends_at alone.
Only show trial if subscription.status === "trialing" AND no active paid subscription overrides it.

Backend rule:
If Stripe says active paid:
- clear or ignore trial display fields
- store status active
- store plan interval/plan label
- store current_period_end as access_until

Add diagnostics:
- show/log raw subscription status, plan, trial_end, current_period_end, cancel_at_period_end in admin/debug logs

Smoke test:

- no “Proefperiode” text
