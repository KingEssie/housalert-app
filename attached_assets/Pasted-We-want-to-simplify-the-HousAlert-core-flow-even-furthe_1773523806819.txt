--------------------------------

Current desired behavior:
When the user taps a match card, do NOT open a separate generic detail screen first.

Instead:
- tapping a match card should open the reaction screen directly

This reaction screen becomes the primary listing screen for the user flow.

Required:
- card tap → reaction screen
- keep this consistent from:
  - matches overview
  - recent matches on home
  - any other common match entry point

--------------------------------
4. REACTION SCREEN REDESIGN
--------------------------------

The reaction screen should become the main action screen.

Layout requirements:

A. Top area
- large listing photo at the top
- back button on the top-left
- price badge on the photo, bottom-right
- do NOT repeat the price again lower on the screen if it is already clearly shown on the photo

B. Directly below the photo
Show:
- listing title first
- then a compact facts block

Facts block should include only useful essentials:
- city
- bedrooms
- size m²
- source
- posted X days ago

Important:
- do not duplicate the posted date if it is already shown elsewhere on the same screen
- do not duplicate the price below if it is already visible on the photo
- keep this block compact so the reaction field starts as high as possible

C. Reaction section
Below the compact facts block:
- show the response letter / reaction content
- make this section more compact if needed so the user can see as much as possible without unnecessary scrolling

D. Main CTA
Keep the main CTA:
- "Kopiëren en reageren" or "Reageer direct" depending on current naming consistency

Behavior must remain:
1. copy reaction text
2. show toast
3. mark match as responded
4. open original external listing URL
