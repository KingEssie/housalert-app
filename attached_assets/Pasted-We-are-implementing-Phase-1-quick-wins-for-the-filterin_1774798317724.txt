==================================================

Current issue:
Target categories are visible/stored but not fully supported end-to-end.

Required:
Make target categories fully functional.

Tasks:
1. Audit current storage for target categories in search profiles
2. Audit current listing-side category/type fields
3. Add/extend extraction so listing categories are populated reliably
4. Normalize source-specific values into canonical categories
5. Ensure matching engine compares search profile target categories against listing categories

- room
- shared
- maisonette

==================================================

Current issue:
Parking is visible as a user-facing filter but not truly backend-ready.

Make parking a real optional feature filter.

Tasks:

   - true

   - null

5. Use description/title keyword extraction where structured data is missing

- Stellplatz
- Parkplatz

PART 3 — MATCHING ENGINE RULES
==================================================

Implement/verify these exact matching rules:

TARGET CATEGORIES:
- user has no preference -> pass
- known category match -> pass
- known category mismatch -> fail
- unknown/null -> pass only if send_unclear = true

PARKING:
- user has no preference -> pass
- listing parking = true -> pass
- listing parking = false -> fail
- listing parking = null -> pass only if send_unclear = true

IMPORTANT:
send_unclear only affects unknown/null.
It must NEVER override a known mismatch.
