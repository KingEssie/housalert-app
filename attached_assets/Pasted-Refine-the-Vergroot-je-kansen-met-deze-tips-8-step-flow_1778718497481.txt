Refine the “Vergroot je kansen met deze tips” 8-step flow.

Current issues:
1. Green link text is hard to read and off-brand.
2. A tip is marked as completed automatically after visiting it.
3. Layout should more closely follow the Rentbird flow structure.

Required behavior:
- A tip should ONLY become completed when the user explicitly checks “Markeer als voltooid”.
- Visiting/opening a tip must NOT mark it completed.
- Pressing “Volgende” without checking completed should move to the next step but leave current tip incomplete.
- Progress percentage must only count manually completed tips.

- Replace all green link text with purple:
  #bbadfb
- Links should be readable and semi-bold.

2. Progress area:

- active progress color #bbadfb

- title next to number

- card background #171429 or #223546

- keep strong contrast

Important: use the Rentbird visual structure:
- number + title at top of card

  “Markeer als voltooid”
