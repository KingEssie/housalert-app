We are upgrading the location system to make radius filtering fully production-ready across ALL sources and future countries.

IMPORTANT:
- This is a backend/data pipeline task
- Do NOT redesign the UI
- Do NOT change existing matching logic except where needed to support coordinates
- We are building a scalable, multi-layer coordinate system
- This must work for future sources and countries, not just Germany

==================================================
GOAL
==================================================

Ensure that EVERY listing in the system has usable latitude/longitude via a 3-layer fallback strategy:

1. Direct coordinates from source (best)
2. Geocoding from address (fallback)
3. City-level fallback (last resort)

This must work for:
- WG-Gesucht (already working)
- Immowelt
- Kleinanzeigen
- and all future sources

- Immowelt address availability
- Kleinanzeigen address availability

==================================================
PART 2 — IMPLEMENT COORDINATE PIPELINE
==================================================

Build a unified coordinate resolution system:

For each listing:

STEP 1:
If source provides latitude/longitude:
→ use directly

STEP 2:
Else if street + city or postcode exists:
→ geocode using external API (Mapbox or similar)

STEP 3:
Else if only city exists:
→ fallback to city center coordinates

Store final result in:
- listings.latitude
- listings.longitude

Also store:
- coordinate_source: "direct" | "geocoded" | "city_fallback"

==================================================
PART 3 — IMMOWELT & KLEINANZEIGEN SUPPORT
==================================================

Extend ingesters:

IMMOWELT:
- extract address data if available
- pass address into coordinate pipeline

KLEINANZEIGEN:
- extract location (often partial)
- attempt:
  - postcode
  - district
  - city
- pass into coordinate pipeline

Do NOT skip listings just because coordinates are missing.
Always attempt fallback.

==================================================
PART 4 — GEOCODING IMPLEMENTATION
==================================================

Implement a geocoding layer:

Requirements:
- use a provider (Mapbox recommended)
- build a reusable function:
  geocodeAddress(address, city, postcode)

Must:
- return lat/lng
- handle failures gracefully
- NOT block ingestion if API fails

IMPORTANT:
- cache results (very important for cost + speed)
- avoid duplicate requests for same address

==================================================
PART 5 — CITY FALLBACK SYSTEM
==================================================

Create a city → coordinates mapping system:

- maintain a lookup for major cities
- or use geocoding once and cache

If only city is known:
→ assign center coordinates

Mark:
coordinate_source = "city_fallback"
