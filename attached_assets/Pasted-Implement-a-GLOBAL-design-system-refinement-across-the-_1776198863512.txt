PART 3 — PASSWORD SCREEN EXACT UX
==================================================

A. TITLE
Use a simple title:
- "Wachtwoord"

Do NOT use:
- "Wachtwoord wijzigen"
unless absolutely required by route naming logic.
Visually the screen title should simply be "Wachtwoord".

B. FIELDS
Use exactly two fields:
1. Wachtwoord
2. Wachtwoord bevestigen

Field style:
- white background
- 1px solid #D1D5DB
- 8px radius
- height ~56–60px
- roomy internal padding
- no lock icons
- optional eye icon only if already supported cleanly

C. PASSWORD TYPE BUG — MUST FIX
There must NEVER be any visible leaked characters between bullets.
Currently there are cases where a visible "3" or "P" appears among masked dots.

Fix this completely:
- input must behave as a real password field
- no character leakage
- masking must be correct at all times

D. LIVE VALIDATION
Under the first password field, show live validation.

Rules:
- minimum 8 characters
- at least 1 uppercase letter
- at least 1 number

Text example:
"Jouw wachtwoord heeft minimaal 8 karakters, 1 hoofdletter en 1 cijfer nodig"

Behavior:
- each condition updates live while typing
- unmet rules = red
- met rules = green
- neutral base text stays dark

E. PROGRESS BAR — MUST BE RULE-BASED
Current progress behavior feels arbitrary.
Fix it so progress is based exactly on rule completion.

Use:
- 0 of 3 rules met = 0%
- 1 of 3 rules met = 33%
- 2 of 3 rules met = 66%
- 3 of 3 rules met = 100%

Color behavior:
- 0/3 = muted red or empty
- 1/3 = orange/yellow
- 2/3 = yellow-green
- 3/3 = green

No fake visual progress.
It must map directly to rule completion.

F. CONFIRM PASSWORD
Second field must validate match with the first field.

If mismatch:
- inline red error text
- submission disabled

G. CTA BUTTON
Use ONE consistent CTA across all password-related flows:

Label:
- "Opslaan"

Do not mix with:
- "Wachtwoord wijzigen"

Behavior:
- disabled until:
  - password is valid
  - confirmation matches
- enabled when all conditions are satisfied

Style:
- primary filled button
- radius 10px
- disabled state visible but still clearly a button
