========================================
1. BACKEND / STRIPE CANCELLATION LOGIC
========================================

When user cancels subscription:

Use Stripe cancellation at period end:
- set cancel_at_period_end = true
- do NOT immediately revoke access

Persist locally:
- subscription_status should become something like:
  active_cancelled / trial_cancelled / cancelling
  OR keep active/trialing but store cancel_at_period_end=true
- store:
  cancel_at_period_end: true
  current_period_end
  canceled_at

Access logic:
- User keeps premium access until current_period_end
- If trialing and cancelled:
  access remains until trial_end/current_period_end
- After current_period_end:
  webhook should mark expired/canceled and revoke premium access

Do not allow duplicate cancel:
- If cancel_at_period_end is already true, cancellation endpoint should return success with current state, not create another cancellation action.
