P1-SUB-01
File: server/routes.ts
Issue:
4 search-profile limit is frontend-only. API can be bypassed to create unlimited profiles.

Fix:
- Enforce max 4 active search profiles server-side.
- Apply to all API routes that create a search profile.
- Count only active/non-deleted profiles if soft delete exists.
- Return 403 or 409 with clear JSON error:
  {
    "error": "profile_limit_reached",
    "message": "Je kunt maximaal 4 zoekopdrachten aanmaken."
  }
- Frontend should display this message if API returns it.
- Do not block editing existing profiles.
- Do not block deleting profiles.
- Do not block restoring only if it would exceed 4 active profiles.

Smoke check:
- User with 3 profiles can create 4th.
- User with 4 profiles cannot create 5th through UI.
- User with 4 profiles cannot create 5th through direct API call.
- Editing existing profile still works.
- Deleting one profile allows creating another.
