- “Rond je account af”
- “Vergroot je kansen met deze tips”

GOAL:
Make onboarding feel like the same premium guided flow system:
- light grey page background
- white rounded content card
- numbered step style (no icons)
- clear progress bar
- left-aligned content
- same bottom navigation style

IMPORTANT:
- Do NOT change the actual onboarding logic
- Do NOT change routing
- Do NOT change validation
- Do NOT change step order
- Do NOT break existing APIs
- This is mainly a layout / presentation refactor

==================================================
1. OVERALL LAYOUT
==================================================

Apply the same visual structure used in the updated guided flows:

- page background: very light grey
- content placed inside a white rounded card
- generous spacing / padding
- clean and minimal layout
- same visual system as the “tips” and “account completion” flows

The onboarding screens should no longer feel like loose full-page forms.

==================================================
2. HEADER / TOP AREA
==================================================

Use the same style as the other flows:

- back button on the left
- flow title centered or visually balanced
- close button on the right
- progress bar directly underneath
- progress counter visible (e.g. 1/3, 2/3, etc.)

Keep it visually consistent with:
- “Rond je account af”
- “Vergroot je kansen met deze tips”

==================================================
3. NUMBERED STEP STYLE
==================================================

Inside each onboarding step screen:

- remove large icons / icon-based hero treatment
- use a numbered step label instead
- e.g.:
  1  Kies je locatie
  2  Stel je voorkeuren in
  3  Controleer en sla op

No hero icon at the top.
No centered illustration.
Use the same numbered visual language as the other flows.

==================================================
4. CONTENT CARD
==================================================

Each onboarding step must place its content inside one main white rounded card.

The card should contain:
- step number + title
- short explanation text
- step-specific content (inputs, search field, list, options, etc.)

Examples:
- location step → search input + city list inside the card
- preferences step → filters inside the card
- review step → summary inside the card

The card should feel like one focused block.

==================================================
5. TEXT ALIGNMENT
==================================================

Match the Rentbird-like style now used in the other flows.

- body text: dark (#111111)

==================================================

- place them inside the white card
