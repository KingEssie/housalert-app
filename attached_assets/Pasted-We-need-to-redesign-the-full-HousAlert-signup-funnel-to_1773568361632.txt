GOAL

Build a 5-screen signup funnel:

==================================================
GLOBAL UX RULES
==================================================

Apply these rules across the full funnel:

1. Inputs must be compact
- flatter / less tall than current
- no oversized rounded bubbles
- cleaner and more structured like the reference

2. No labels above fields on step 4
- use placeholder text inside the input fields
- especially on the account creation screen
- compact layout is important

3. Focus state
- when user taps an input field, show a clear blue focus border / outline
- make the active field obvious

4. Layout rhythm
- keep the same visual hierarchy as the reference:
  - intro text
  - progress dots
  - white content card
  - fields
  - helper/info box if relevant
  - CTA

5. Mobile-first
- match spacing and flow of the screenshots
- do not make it feel like generic internal forms
- it should feel like a polished consumer conversion funnel

6. HousAlert styling
- use HousAlert typography, colors, buttons, and logo
- but preserve the conversion-oriented structure of the reference
- dark navy HousAlert primary text, blue actions, white cards, light backgrounds
