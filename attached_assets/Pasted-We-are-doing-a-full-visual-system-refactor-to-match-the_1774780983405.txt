==================================================
CREATE A GLOBAL DESIGN SYSTEM
==================================================

Create or refactor a central design system (tokens + reusable styles).

Define:

COLORS:
- background: soft light gray
- card: pure white
- primary text: near-black
- secondary text: muted gray
- accent pink: consistent across buttons/icons
- success green: soft (not neon)
- border: subtle gray

TYPOGRAPHY:
- headings: bold, tight spacing
- body: clean, slightly smaller than current if needed
- secondary text: lighter gray
- consistent font usage everywhere (NO random variations)

SPACING SYSTEM:
Use a consistent scale:
- 4 / 8 / 12 / 16 / 20 / 24 px

CARD SYSTEM:
- border radius: 6px ONLY
- consistent padding (16px or 20px max)
- subtle border
- minimal shadow

BUTTON SYSTEM:
- height: 56px
- radius: 6px
- consistent font + weight
- consistent gradient/pink usage

LIST / ROW SYSTEM:
- row height: 56px
- consistent vertical alignment
- left icon + label + right action alignment fixed

PROGRESS BARS:
- consistent height
- soft gray background
- controlled accent color

ICONS:
- consistent size across app
- consistent stroke weight
- no mixing styles
