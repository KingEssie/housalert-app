We are committing fully to a Rentbird-style design system.

The current app is a mixed hybrid (light HousAlert + partial dark Rentbird).
This must be completely removed.

GOAL:
Rebuild ALL active UI screens to match Rentbird-style design exactly.

IMPORTANT:
This is NOT a redesign of logic or flow.
This is a FULL visual transformation.

DESIGN SYSTEM (STRICT):

BACKGROUND:
- Dark purple / navy gradient or solid (#1A1A2E or similar)
- No light backgrounds anywhere

CARDS:
- Dark cards (slightly lighter than background)
- Rounded corners (16–20px)
- Soft shadows or subtle elevation

PRIMARY COLOR:
- Pink / magenta (Rentbird style)
- Used for ALL primary buttons

TEXT:
- White / off-white for main text
- Grey for secondary text

INPUTS:
- Light (almost white) input fields on dark background
- Rounded, large (50–60px height)

BUTTONS:
- Primary: pink filled, rounded, bold text
- Secondary: outlined pink

ICONS:
- White or soft colored
- Consistent stroke

BOTTOM NAV:
- Dark background
- Active tab highlighted (pink or white)
- Inactive grey

NO:
- No blue primary color
- No orange CTAs
- No white screens
- No mixed styles
- No leftover HousAlert design

1. Welcome / Login
2. Signup
3. Onboarding flow
4. Home

6. Tips

8. Profile

- Redesign the FULL screen
