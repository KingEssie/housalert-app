Redesign the existing HousAlert Admin dashboard into a premium mobile-first SaaS control center. Keep the current data and existing backend logic intact as much as possible, but completely improve the information architecture, UI hierarchy, and mobile app feel.

IMPORTANT:
- Mobile-first only
- The admin must feel like a real mobile app, not a desktop admin squeezed into a phone
- Add a fixed bottom tab bar for navigation
- Keep implementation efficient
- Do minimal smoke checks only, avoid extensive testing
- Reuse existing data fetching/hooks/services wherever possible
- Do not rebuild backend logic unless necessary
- Preserve all existing admin functionality, but present it in a cleaner, friendlier, more premium way

GOAL:
Transform the admin dashboard from a data-heavy admin panel into a decision-focused mobile command center:
1. Show what needs attention first
2. Group metrics into logical sections
3. Reduce table overload
4. Improve spacing, hierarchy, and clarity
5. Make everything feel smooth, modern, and premium

DESIGN DIRECTION:
Use a clean premium mobile UI inspired by modern fintech/productivity apps:
- soft background
- rounded cards
- subtle shadows
- strong spacing
- large readable headings
- minimal clutter
- clear priority hierarchy
- soft status colors
- swipe-friendly layouts where helpful
- premium feel similar to a modern banking app / Stripe-style light UI / Linear-inspired clarity
- keep the HousAlert branding and overall blue accent, but refine it

GENERAL UI RULES:
- Use consistent 16–20px horizontal padding
- Use large section titles
- Use cards for grouped information
- Replace large dense tables with card/list layouts where possible on mobile
- Only keep tables where truly necessary
- Status badges should be visually clear:
  - green = healthy / active / operational
  - yellow = warning
  - red = broken / failed / urgent
  - blue = neutral info / selected
- Improve typography hierarchy:
  - page title
  - section title
  - metric label
  - metric value
  - helper/meta text
- Avoid showing too many raw metrics at once
- Prioritize clarity and decision-making over completeness above the fold

APP STRUCTURE:
Create a fixed bottom tab bar with 5 main tabs:
1. Dashboard
2. Growth
3. Sources
4. Users
5. System

Each tab should feel like its own mobile app page.

BOTTOM TAB BAR:
- Fixed at bottom
- Rounded top container or premium native-app style bar
- Icons + labels
- Active tab highlighted with brand blue
- Keep spacing generous and tap targets large
- Smooth transitions between tabs

TOP HEADER:
On each main tab:
- Show a clean compact top header
- Left: page title or greeting
- Right: small action icons where relevant (refresh, alerts, search)
- Keep “Back to app” accessible but less dominant than now
- Remove the current cluttered segmented-navigation feel
