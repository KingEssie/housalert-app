Refine the Subscription (Abonnement) section inside the Profile screen.

IMPORTANT:
- Keep HousAlert branding (colors, fonts, buttons)
- Do NOT create a separate page
- Only update the layout and structure of the subscription card

==================================================
1. CENTERED LAYOUT STRUCTURE
==================================================

The entire subscription card content must be CENTERED horizontally.

Structure (top → bottom):

1. Icon (centered)
2. Subscription type (centered)
3. Renewal text (centered)
4. Optional cancel button (if active)

Spacing must be balanced and consistent.

2. CONTENT STRUCTURE
==================================================

When user HAS an active subscription:

Display in this exact order:

- Icon (subscription / crown / premium style icon)

  Examples:

  - Proefabonnement
  - Jaarabonnement

- Renewal text:
  Format:
  "Wordt automatisch verlengd op maandag 7 april 2026"

Rules:
- date must be human readable (Dutch format)
- no timestamps
- no technical billing language

Everything centered.

  - soft border or very subtle shadow
  - rounded corners

- Icon:
  - slightly larger than normal UI icons
  - HousAlert accent color

- Text:
  - subscription name: bold, slightly larger
  - renewal text: smaller, softer gray

- spacing:
  - generous vertical spacing between elements
  - must feel calm and premium

==================================================

==================================================

If user has an active subscription:

"HousAlert opzeggen"
