Use the blurred house illustration as the global fallback image for listings without photos.

Context:
We have a new blurred house illustration that should be used ONLY when a rental listing has no image/photo.

Important distinction:
This is NOT for empty pages like “No matches yet”.
This is ONLY for listing cards/details/emails/widgets where a specific listing has missing/empty/broken imageUrl.

Goal:
If a listing has no image, every surface should show the same blurred house fallback image.

Surfaces:
- app Matches cards
- app Favorites cards
- app Listing detail page
- public homepage widget
- public city listing embeds
- emails containing listing cards
- any other listing preview/card UI
- admin listing previews if applicable

DO NOT touch:
- ingestion
- matching
- push notifications
- Stripe
- service worker
- city filtering
- SEO page layout
- business logic

==================================================
1. Add shared fallback image asset
==================================================

Add the blurred house image as:

client/public/assets/listing-fallback-house.png

or the existing public assets folder if the project uses a different convention.

Use a stable public URL such as:

/assets/listing-fallback-house.png

Optimize/compress if needed.

==================================================
2. Create shared image fallback constant/helper
==================================================

Create or update a shared constant/helper:

LISTING_IMAGE_FALLBACK = "/assets/listing-fallback-house.png"

Use this anywhere listing imageUrl can be missing.

==================================================
3. App image fallback
==================================================

Update listing image rendering in:
- Matches listing cards
- Favorites listing cards
- Listing detail screen
- any shared ListingCard component

Logic:
- if imageUrl is null/undefined/empty → fallback image
- if image fails to load → fallback image via onError
- avoid infinite onError loop

Keep existing styling:
- object-fit: cover
- rounded corners

client/public/widget.html
